# Execute e publique seu app do AI Studio

Este repositório contém tudo o que você precisa para rodar seu aplicativo localmente.

Veja seu app no AI Studio: https://ai.studio/apps/drive/1lKsZtXZW3WdJ0-fefIjnUll_noHIcV_8

## Execução Local

**Pré-requisitos:** Node.js

1. Instale as dependências:
   `npm install`
2. Configure a `GEMINI_API_KEY` no arquivo [.env.local](.env.local) com sua chave de API do Gemini
3. Inicie o aplicativo:
   `npm run dev`
